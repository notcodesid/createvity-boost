# Creativity

**Think better. Create more.**

---

## The problem

I know the science of creativity — walk when stuck, capture immediately, separate generation from evaluation — and I still fail to run the system.

Creative tools are either empty notes apps or AI that writes *for* you. Neither helps you **actually run** a process. What’s missing is a protocol you can follow when your brain won’t cooperate.

---

## How it actually feels

This is what I’m stuck in, over and over:

1. **Ideas die unrecorded** — not because I stop having them, but because I don’t write them down in the moment.
2. **The inner critic shows up too early** — mid-generation, it kills volume before anything good can surface.
3. **Blank pages freeze me** — total freedom is the enemy; I need constraints, not another empty doc.
4. **Work never leaves the notebook** — the studio door stays closed. I refine privately and never ship.

I don’t need another place to type. I need something that forces capture, blocks judgment until later, unsticks me when I’m empty, and makes shipping public so I can’t lie to myself.
